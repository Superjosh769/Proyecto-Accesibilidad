# 🧠 Sistema Inteligente de Navegación para Personas con Discapacidad Visual

## 🚀 Descripción
Este proyecto consiste en el desarrollo de un sistema tecnológico diseñado para mejorar la movilidad y seguridad de personas con discapacidad visual.

A través del uso de sensores ultrasónicos, el sistema detecta obstáculos en el entorno y traduce esa información en vibraciones, permitiendo al usuario percibir su entorno sin necesidad de visión.

---

## 🎯 Problema
Millones de personas con discapacidad visual enfrentan riesgos diarios al desplazarse en entornos urbanos debido a la falta de herramientas accesibles que les permitan detectar obstáculos de manera eficiente.

---

## 💡 Solución
Se desarrolló un sistema portátil basado en sensores ultrasónicos conectados a un microcontrolador que procesa la distancia y activa motores de vibración con distinta intensidad dependiendo de la cercanía del obstáculo.

---

## ⚙️ Tecnologías utilizadas
- Arduino Nano  
- Sensores ultrasónicos  
- Motores de vibración  
- Transistores 2N2222A  
- Diodos  
- Programación en Arduino (C/C++)  
- Desarrollo web (HTML, CSS, JavaScript)

---

## 🧪 Funcionamiento
1. El sensor ultrasónico mide la distancia a los objetos  
2. El microcontrolador procesa la información  
3. Se activa un motor de vibración  
4. La intensidad de la vibración aumenta al acercarse al obstáculo
