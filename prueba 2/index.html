Sistema Inteligente de Navegación

Tecnología que guía, seguridad que transforma

Problema

Las personas con discapacidad visual enfrentan obstáculos difíciles de detectar.

Solución

Sistema de sensores que detectan obstáculos y alertan mediante vibraciones.

Arquitectura del Sistema

Sensores ultrasónicos + microcontrolador + vibración inteligente.

Materiales

Arduino Nano

Jumpers

Sensores ultrasónicos

Motores de vibración

Diodo
